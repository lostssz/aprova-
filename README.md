# Aprova+

Protótipo de uma landing page para apresentação escolar do MVP **Aprova+**, uma proposta de reforço e preparação online para ENEM, vestibulares e concursos.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Estrutura

```text
aprova-/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como executar no VS Code

1. Clone o repositório.
2. Abra a pasta no VS Code.
3. Instale a extensão **Live Server**, se ainda não tiver.
4. Clique com o botão direito em `index.html`.
5. Selecione **Open with Live Server**.

Também é possível abrir o arquivo `index.html` diretamente no navegador.

## Funcionalidades do protótipo

- Layout responsivo
- Menu para celular
- Navegação suave pelas seções
- Seção de disciplinas
- Explicação do funcionamento
- Plano único de R$ 70/mês
- FAQ interativo
- Formulário demonstrativo com validação
- Animações discretas ao rolar a página

> Este repositório é um protótipo escolar. O formulário não envia dados para um servidor e não existe processamento real de pagamento.
